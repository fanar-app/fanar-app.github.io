Laravel

Register the Fanar service provider and every request, query, exception, and cache event is captured automatically. Zero boilerplate.

Installation

composer require fanar/fanar

Register the service provider

// config/app.php
'providers' => [
    // ...
    Fanar\Laravel\FanarServiceProvider::class,
],

Environment variables

# .env
FANAR_HOST=127.0.0.1
FANAR_PORT=23517
FANAR_ENABLED=true
VariableDefaultDescription
FANAR_HOST127.0.0.1Hostname of the machine running Fanar
FANAR_PORT23517Port the Fanar desktop app is listening on
FANAR_ENABLEDtrueSet to false to disable without removing the provider

What gets captured automatically

  • Every HTTP request — method, path, status, duration, query count
  • All Eloquent / DB queries — SQL, bindings, execution time
  • Uncaught exceptions — with stack trace
  • Cache hits and misses
  • Queued jobs — dispatch and execution

Manual calls

You can also call Fanar directly anywhere in your Laravel app.

use Fanar\Fanar;

// In a controller, service, command, job — anywhere
Fanar::log('processing order #' . $order->id);
Fanar::dump($order->toArray());
Fanar::exception($e);
